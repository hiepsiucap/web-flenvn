# Local fonts

These variable fonts are bundled so production builds do not need to download fonts from Google.

- `Nunito-Variable.ttf`: [Google Fonts Nunito](https://github.com/google/fonts/blob/main/ofl/nunito/Nunito%5Bwght%5D.ttf), licensed under `Nunito-OFL.txt`.
- `GeistMono-Variable.ttf`: [Google Fonts Geist Mono](https://github.com/google/fonts/blob/main/ofl/geistmono/GeistMono%5Bwght%5D.ttf), licensed under `GeistMono-OFL.txt`.
